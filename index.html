How it works

One tab per flow

Each tab starts where the code starts: an API call, a webhook, a job or an event. Then it lists the 3 to 5 files that run, in the order they run.

A summary for each file

Open a file and the panel says what this PR changes in it, for the flow you're on. One summary per flow says how the files fit together.

Click to open

Click a box or a file and it opens in the editor at the right line. The sidebar groups every changed file and opens its diff.

Ask Cursor's chat

The chat on the right knows which flow, file and lines you're looking at. Ask "why does this skip the charge?" and it answers about that spot.

Stays on your machine

The diagram is drawn offline by a pinned copy of PR Lens. Nothing is posted to GitHub. Map files stay out of git.

Shows where money moves

If a flow ends in a charge, payout or transfer, that box is in the diagram and the summary says so.

Use it

  1. Install with the command above, then reload Cursor (Cmd+Shift+P → Developer: Reload Window).
  2. Check out the PR's branch.
  3. Click Map this PR in the PR Map tab of the bottom panel. It takes 2 to 8 minutes.
  4. Pick a flow and read its files in order.

You need

  • Cursor
  • Claude Code, signed in
  • Node 20.7 or newer
  • GitHub CLI, signed in

A map costs about $1 to $2 of Claude usage. Arrows and summaries are an AI's reading of the code, so check them against the diff.

Remove it

cursor --uninstall-extension kikoff-local.pr-map
rm -rf ~/.claude/skills/pr-map
