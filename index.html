Read an AI-written PR in story order

Kode Visualizer maps a PR inside Cursor. Each flow gets its own tab: what starts it, the 3 to 5 files to read in order, and what this PR changes in each one. Click a box and the file opens.

- read 32 changed files in whatever order GitHub lists them
+ follow 3 flows from the API call to the money, one file at a time
Paste this in Terminal 
curl -fsSL https://…/install.sh | bash

It checks what you need, installs the skill and the Cursor extension, and changes nothing if something is missing. Or download the zip and run bash install.sh pr-map-0.1.0.zip.

Use it

  1. Install with the command above, then reload Cursor (Cmd+Shift+P → Developer: Reload Window).
  2. Check out the PR's branch.
  3. Click Map this PR in the PR Map tab of the bottom panel
  4. Pick a flow and read its files in order.

You need

  • Cursor
  • Claude Code, signed in
  • Node 20.7 or newer
  • GitHub CLI, signed in

Remove it

cursor --uninstall-extension kikoff-local.pr-map
rm -rf ~/.claude/skills/pr-map
